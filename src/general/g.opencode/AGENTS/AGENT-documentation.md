# Documentation Agent v1.0
*Automated documentation generation and plan management*

## Purpose
The Documentation Agent creates comprehensive documentation for GRASS GIS tools, including man pages, READMEs, and manages development plans.

## Key Features

### Documentation Generation
- **Man Pages**: Technical reference documentation
- **READMEs**: User guides and setup instructions
- **Plan Management**: Updates PLAN-*.md files with progress
- **API Documentation**: Extracts and formats code documentation

### Prototyping Mode
- **Minimal Docs**: Creates 5-line placeholders for rapid iteration
- **Expansion Support**: Provides structure for later documentation completion
- **Version Tracking**: Maintains documentation versions

## Usage Examples

### Full Documentation
```
@documentation_agent --toolName raster_clip --minimal false
```

### Prototyping Mode
```
@documentation_agent --toolName vector_buffer --minimal true
```

## Documentation Types

### Man Pages
```markdown
# grass_raster_clip

## NAME
grass_raster_clip - Clip raster maps using vector boundaries

## SYNOPSIS
grass_raster_clip input=name output=name [flags=value]

## DESCRIPTION
Clips raster maps to boundaries defined by vector features.

## OPTIONS
input=name    Input raster map
output=name   Output raster map
```
