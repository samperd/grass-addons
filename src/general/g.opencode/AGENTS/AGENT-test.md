# Test Agent v1.0
*Automated test generation and execution for GRASS tools*

## Purpose
The Test Agent creates comprehensive test suites for GRASS GIS tools, including unit tests, integration tests, and mock setups for automated validation.

## Key Features

### Test Generation
- **Pytest Templates**: Creates complete test files with proper structure
- **Mock Setup**: Configures mocks for GRASS commands and external dependencies
- **Coverage Analysis**: Runs tests with coverage reporting
- **Edge Case Testing**: Generates tests for error conditions and boundary cases

## Test Structure Generation

### Test File Template
```python
"""
Test suite for {toolName} GRASS GIS tool
"""

import pytest
import sys
import os
from unittest.mock import patch, MagicMock

# Add tool to path
sys.path.insert(0, os.path.join(os.path.dirname(__file__), '..', '.opencode', 'tool'))

class Test{toolName}:
    def test_basic_functionality(self):
        # Mock GRASS calls
        with patch('subprocess.run') as mock_run:
            mock_run.return_value = MagicMock(returncode=0, stdout='success')
            # Test execution
            result = {toolName}.main()
            assert result.success == True

    def test_error_handling(self):
        # Test error scenarios
        with patch('subprocess.run') as mock_run:
            mock_run.return_value = MagicMock(returncode=1, stderr='error')
            with pytest.raises(SystemExit):
                {toolName}.main()
```

## Mock Configuration

### GRASS Command Mocking
```python
@pytest.fixture
def mock_grass_commands():
    with patch('subprocess.run') as mock_run:
        mock_run.return_value = MagicMock(
            returncode=0,
            stdout='GRASS operation completed',
            stderr=''
        )
        yield mock_run
```

### File System Mocking
```python
@pytest.fixture
def mock_file_system(tmp_path):
    # Create temporary test files
    input_file = tmp_path / 'input.tif'
    output_file = tmp_path / 'output.tif'
    input_file.write_text('mock raster data')
    return {'input': str(input_file), 'output': str(output_file)}
```

## Integration Points

### OpenCode Tools
- Invoked via `@test_agent` commands
- Results used by Quality Agent for validation

### File System
- Writes: Test files to `testsuite/` directory
- Reads: Generated code from Code Generation Agent

### Other Agents
- **Orchestrator**: Called after code generation
- **Code Generation**: Analyzes generated code for test creation
- **Quality Agent**: Validates test quality and coverage
